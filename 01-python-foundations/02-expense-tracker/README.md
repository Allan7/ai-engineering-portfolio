# Expense Tracker

A simple Python command-line expense tracker built as part of my Python foundations portfolio.

The aim of this project is to practise structuring data, working with user input, and building a slightly more organised program using functions, lists, and dictionaries.

## Version 1 Goals

The first version will allow the user to:

- Enter multiple expenses
- Give each expense a name
- Enter an amount
- Assign a category
- Store all expenses entered
- Display the recorded expenses
- Calculate the total amount spent
- Choose when to stop entering expenses

## Concepts Practised

- Variables
- Strings and numeric data
- Lists
- Dictionaries
- Loops
- Conditional logic
- Functions
- User input
- Input validation
- Calculating totals

## Planned Structure

Each expense will contain:

- Expense name
- Amount
- Category

Multiple expenses will then be stored together so they can be displayed and analysed.

## Future Improvements

Possible later versions may include:

- Spending totals by category
- Editing or deleting expenses
- Saving expenses to a file
- Loading previous expenses
- Monthly budgets
- Budget warnings
- CSV or JSON storage
- Summary reports

This project forms part of my wider AI engineering learning portfolio.
